# Data Contracts

Um contrato de dados define o esquema, os tipos, as chaves e as regras de negócio de um ativo. Na demonstração, um contrato pode exigir uma chave de pedido válida e uma receita não negativa. A validação acontece antes do consumo analítico.

A data contract defines the schema, types, keys and business rules of an asset. In this demonstration, a contract can require a valid order key and nonnegative revenue. Validation happens before analytical consumption.
