# Bronze, Silver e Gold

A camada Bronze preserva a origem bruta para rastreabilidade. Silver padroniza tipos e aplica contratos. Gold concentra dados validados e modelados para análise e indicadores. Cada camada tem uma responsabilidade distinta.

The Bronze layer preserves raw inputs for traceability. Silver standardizes types and applies contracts. Gold provides validated, modeled data for analysis and metrics. Each layer has a distinct responsibility.
