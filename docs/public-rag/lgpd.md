# LGPD e minimização

A LGPD orienta a proteção de dados pessoais. A minimização limita a coleta e a distribuição ao necessário para a finalidade declarada. O perfil público da demonstração usa dados sintéticos. Nenhum exemplo reproduz dados pessoais reais.

Brazil's LGPD guides personal data protection. Data minimization limits collection and distribution to what the declared purpose requires. This public demonstration uses synthetic data. Its examples contain no real personal data.
