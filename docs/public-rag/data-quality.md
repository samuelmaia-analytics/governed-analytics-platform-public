# Data Quality

Os controles de qualidade verificam integridade, consistência e regras configuradas. Uma pontuação de qualidade 100/100 significa que nenhuma regra configurada foi reprovada. Um campo pode conter nulos quando o contrato permite.

Data quality checks measure integrity and consistency against configured rules. A quality score of 100/100 means no configured check failed. Null values can exist when the contract permits them.
