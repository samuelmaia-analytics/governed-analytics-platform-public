# Escopo do pacote fonte do GAP

O ZIP reúne código, contratos, configurações de execução, testes selecionados e cinco documentos técnicos. A revisão técnica verifica os bytes. A distribuição exige autorização explícita por caminho, versão e SHA-256, com finalidade `documentation_preview` e público `public`.

Entradas Olist, datasets derivados, exports, relatórios pendentes, capturas de tela e evidências operacionais privadas ficam fora. Os testes incluídos usam dados sintéticos. Os controles de distribuição usam uma política de bloqueio sem o inventário operacional privado.

O processamento integral requer entradas autorizadas para uso privado. O perfil público exige autorização específica para a amostra sintética. O navegador público de documentos verifica a autorização de visitante, o hash e a revogação. O Publication Gate continua ativo.

O ZIP contém a árvore fonte selecionada. A divulgação de dados, do histórico Git ou do repositório e o deploy exigem decisões próprias.
